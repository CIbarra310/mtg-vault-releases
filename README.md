# MTG Vault downloads

Builds of MTG Vault, an app for tracking your Magic: The Gathering
collection, decks, sets and prices. Get the latest version from
[Releases](../../releases/latest).

| Platform | File |
| --- | --- |
| Windows | `mtg-vault-windows-x64.zip`: extract and run `mtg_vault.exe` |
| Android | `mtg-vault-android.apk`: open it on the device to install |
| macOS | `mtg-vault-macos.zip` |
| Linux | `mtg-vault-linux-x64.tar.gz` |

The app checks here for new versions and offers to update.
